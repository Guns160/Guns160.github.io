Privacy Notice

隐私说明

1. 个人自用

Claude Gmail MCP 用于本人在桌面 Claude 中处理自己的 Gmail 邮件，不向其他用户分发客户端配置。通过 Google API 获取的数据仅用于本人请求的邮件功能，按 Google API Services User Data Policy 及 Limited Use 要求处理，不出售邮件数据，不用于广告。

2. 说明网站

本静态网站不调用 Gmail API，不收集邮件，也没有登录、表单或分析脚本。网站由 GitHub Pages 托管。GitHub 可能记录 IP 地址、访问时间及请求路径等访问日志，按 GitHub 隐私声明处理。

3. 邮件处理

本人授权后，桌面集成可通过 gmail.modify 读取和修改邮件、标签及草稿。任务相关的主题、正文、邮件地址等内容可能经 Google MCP 及 Claude 当前配置的模型服务处理。具体传输范围、日志和模型训练设置取决于所用服务与账号配置。授权范围本身不表示已执行任何邮件操作；实际操作取决于本人请求及连接器所支持的功能。

4. 凭据与保留

客户端密钥和授权令牌应保存在本人管理的本机客户端，不写入本网站。令牌、对话和邮件上下文的保留与删除按实际客户端及服务设置执行；本网站不保存这些内容。

5. 撤销访问

本人可在 Google 账号的第三方连接中撤销该应用。撤销不会自动删除已发送至 Claude 或模型服务的内容；这些内容需在对应服务中另行删除。
